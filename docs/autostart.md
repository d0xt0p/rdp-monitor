# Автозапуск в графическом сеансе

Сначала запустите приложение вручную и проверьте GUI, подключение и звук. Затем скопируйте шаблон:

```bash
mkdir -p ~/.config/autostart
cp examples/rdp-monitor.desktop ~/.config/autostart/rdp-monitor.desktop
```

Откройте полученный файл в текстовом редакторе и замените пример `/home/user/bin/rdp-monitor/rdp-monitor.sh` на **абсолютный путь** к вашему скрипту. `~` и `$HOME` в поле `Exec` не раскрываются. Если путь содержит пробелы, заключите его в двойные кавычки.

Пример использует имя VPN-интерфейса `tun0` и звуковой файл `alert.mp3` рядом со скриптами. Чтобы выбрать другие значения, замените строку `Exec`, например:

```ini
Exec=env RDP_MONITOR_VPN_INTERFACE=tun0 RDP_MONITOR_ALERT_FILE=/home/user/Music/alert.wav /home/user/bin/rdp-monitor/rdp-monitor.sh autostart
```

Это обезличенный пример: замените пути на свои. Для путей с пробелами используйте кавычки вокруг соответствующего аргумента, например `"RDP_MONITOR_ALERT_FILE=/home/user/My Music/alert.wav"`.

Выйдите из графического сеанса и войдите снова. Приложение должно запуститься один раз. Не создавайте второй аналогичный пункт автозагрузки. Повторный `autostart` при уже работающем мониторе может не открыть GUI из-за раннего выхода команды запуска; в таком случае выполните `./rdp-monitor.sh gui`.

Для отключения удалите только созданный пункт `~/.config/autostart/rdp-monitor.desktop` и остановите монитор командой `./rdp-monitor.sh stop`. Закрытие окна само по себе монитор не останавливает.
