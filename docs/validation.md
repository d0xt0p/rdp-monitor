# Проверка v1.0.0

Публичная сборка подготовлена из актуальных `rdp-monitor.sh` и `rdp-monitor-gui.tcl` архива `bin.zip`. GUI перенесён без изменения логики. Изменения Bash перечислены в CHANGELOG.

## Выполнено при подготовке публикации

Проверки проведены в Windows с Bash 5.3 из Git и Tcl/Tk 8.6.12. Временный каталог, вымышленные сетевые адреса и тестовые профили отделены от исходников и рабочих настроек.

- Синтаксис Bash проверен командой `sh -n` интерпретатором GNU Bash.
- С подставной командой `ss` проверены состояния RDP без соединения и с установленным соединением Remmina на порту 3389.
- С подставными `ip`, `curl` и `flock` проверены выбор нестандартного имени VPN-интерфейса, активный и отсутствующий интерфейс, успешный основной интернет-запрос, переход к резервному сайту и недоступность обоих сайтов. Блокировка `flock` на Linux этими проверками не подтверждается.
- На временных профилях Remmina, включая вложенную папку и имя с пробелом, проверены обнаружение `keyboard_grab=0`, добавление отсутствующего параметра, успешная повторная проверка и сохранение исходного файла в `.bak`.
- Загружен настоящий GUI Tcl/Tk с имитацией ответа Bash и Linux-признака исполняемого файла. Проверены создание кнопок, индикатор RDP и удаление GUI PID-файла при выходе. Окно оставалось скрытым.
- Проверена UTF-8-кодировка и LF-окончания строк; в распространяемый каталог включены только подготовленные исходники и документация. Служебные файлы и звук из рабочей установки не добавлялись.

Это проверки подготовленной сборки с имитацией окружения, а не полноценный прогон на ALT Linux.

## Проверка на целевом ALT Linux

1. Запустить `paplay` с выбранным аудиофайлом и убедиться, что звук слышен.
2. Выполнить `./rdp-monitor.sh autostart`, затем подключиться через Remmina на TCP-порт 3389. Убедиться, что виден статус подключения.
3. Разорвать тестовое соединение. Примерно через десять секунд проверить тревогу и кнопку отсрочки на минуту.
4. Восстановить соединение и проверить прекращение звука.
5. Проверить изменение статуса VPN и интернета, не вмешиваясь в рабочие соединения.
6. Проверить остановку монитора, закрытие GUI и повторный запуск, затем автозапуск при входе в сеанс.

Реальные соединения, звук, блокировки процессов, остановка/перезапуск и автозапуск в ALT Linux при подготовке публичной сборки не проверялись. Их работоспособность не заявляется как подтверждённая этими локальными проверками.
