# История изменений

## v1.0.0 — 2026-11-23

Первый публичный выпуск из последней рабочей копии `bin.zip`. Это начало публичной истории; старым резервным копиям номера релизов не присваивались.

Включены существующие функции: монитор TCP-соединения Remmina, тревога и её отсрочка, GUI Tcl/Tk, проверка VPN-интерфейса и интернета, проверка и исправление `keyboard_grab`, запуск Remmina.

При подготовке публикации:

- Заменены названия, привязанные к конкретной организации, на нейтральные.
- Добавлены `RDP_MONITOR_VPN_INTERFACE` (по умолчанию `tun0`) и `RDP_MONITOR_ALERT_FILE` (по умолчанию `alert.mp3` рядом со скриптом).
- Убраны параметры отключения проверки HTTPS-сертификатов.
- Установлена маска прав `077` для новых служебных файлов.
- Добавлены README, инструкция автозапуска, шаблон и лицензия MIT.
- Исключены состояние, PID-файлы, блокировки, резервные копии и аудиофайл с неподтверждёнными правами распространения.

MQTT / Home Assistant в этот выпуск не входят.
